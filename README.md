# AI Product Studio

Локальное приложение для разработки, запуска и проверки AI pipeline.

## Запуск

```bash
npm install
npm run dev
```

Основной интерфейс открывается по адресу `http://127.0.0.1:3000/`. Экраны MVP выбираются параметром `?view=<view>`.

## Актуальные спецификации

- [AI Атрибуты в Заявке](docs/application-attributes.md) — каноническое описание текущего pipeline из 7 этапов, контрактов и CRM-поведения.
- Документы `docs/application-attributes-local-v*.md` и RTF-файлы в корне сохраняются как история изменений и исходные материалы. Исполняемая версия определяется кодом, указанным в канонической спецификации.

## Проверки

```bash
npm run lint
npm run build
npm test
npm run test:smoke
```

Полный набор тестов может занимать значительное время. Для точечных изменений запускайте связанные Vitest и Playwright spec-файлы.
